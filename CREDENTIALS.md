# Учетные данные для входа в систему

## Роли пользователей

Система поддерживает следующие роли:

- **guest** (Гость) - роль по умолчанию, не требует авторизации
- **waiter** (Официант) - требуется авторизация с паролем
- **admin** (Администратор) - требуется авторизация с паролем

## Пароли для входа

| Роль | Пароль |
|------|--------|
| Официант (waiter) | `waiter2026-cafe` |
| Администратор (admin) | `admin2026-cafe` |
